## [0.1.0] - 2026-09-08

### Added

- Interactive `coconut` terminal interface for assigning the Copilot key.
- Linux input integration using evdev, uinput and systemd.
- Windows user-session support for the standard `Win + Shift + F23` chord.
- Application, browser, website, path, terminal and command actions.
- Linux and Windows release packaging with GitHub Actions.
