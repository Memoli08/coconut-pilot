# Support

Use the GitHub issue forms for reproducible bugs and concrete feature requests.

Before opening an issue, run:

```sh
coconut doctor
coconut status
```

Include the operating system, desktop environment or Windows version, Coconut
version, and the smallest reproducible sequence. Remove personal paths, URLs
and secrets from logs before sharing them.

Security reports belong in the private process described in
[SECURITY.md](SECURITY.md), not public issues.
